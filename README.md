## 如何运行

目前仅支持从源码运行。

**环境要求**：Python 3.10+（Windows / macOS / Linux 均可）

```bash
# 1. 克隆仓库
git clone <repo-url>
cd shiori

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动
python main.py
```

首次启动时会自动在 `~/.shiori/` 下生成 `config.json`（数据目录，课程缓存与日志也存放在这里）。打开设置对话框填入教务系统账号（newjw 或 cas，newjw 优先，失败自动换 cas）以及学年学期后即可开始使用。

sudo apt install fcitx5-frontend-qt6

## 如何使用

基本排课流程如下：

1. **配置账号**：在设置对话框中填入教务系统账号（`hdu.newjw` 或 `hdu.cas`）和学年学期（如 `2026` / `1`）。
2. **同步课程池**：点击信息面板中的「更新课程池」按钮，从教务系统在线拉取本学期全部可选课程（任务落实聚合较慢，高峰期可能需要较长时间，请耐心等待）。
3. **勾选课程**：在右侧课程列表中勾选心仪的教学班，左侧课表网格会实时预览周课表、学分统计与时间冲突（冲突课程在信息面板中以红色标出）。
4. **同步个人课表**：点击「更新个人课表」，从教务系统拉取已选课数据；信息面板会自动对比本地勾选与教务实际选课，用不同颜色标注**补选**（本地有、教务无）、**退选**（教务有、本地无）与**冲突**，作为去教务系统操作的清单。
5. **导出课表**：课表视图支持导出为 PNG 图片。

所有配置（课表节次时间、学期周数、列显示、学分上限等）都可在设置对话框中调整，或直接编辑 `~/.shiori/config.json`。

## 搜索语法

课程列表顶部的搜索框支持按任意信息过滤，并有简单的组合语法（优先级 `!` > `|` > 空格，即 **非 > 或 > 且**）：

| 语法 | 含义 | 示例 |
| --- | --- | --- |
| 空格 | 且（AND） | `计算机网络 肖周芳` = 同时包含「计算机网络」与「肖周芳」 |
| `\|` | 或（OR），仅对**时间/教师**字段生效 | `肖周\|王晓` = 教师为「肖周」或「王晓」 |
| `!` | 非（NOT），仅对**课程名/教师(含工号)/时间/校区**生效 | `!肖周芳`、`!下沙`、`!1-2节` |

各字段的匹配方式不同：

- **课程名 / 开课学院**：子序列匹配，支持简写——`计网` → 「计算机网络」、`计院` → 「计算机学院」。
- **教师姓名**：中文模糊包含（`肖周` 匹配「肖周芳」），并支持拼音首字母缩写（前缀严格：「肖周芳」→ `xzf`，`xz` 命中、`xf` 不命中）；多位教师任一命中即可。
- **教师工号 / 课程代码 / 学分**：全文匹配（大小写不敏感），多工号（如 `01034,41015`）拆开后逐个匹配。
- **教学班名称**：有无学年学期前缀均可——`A0100591-01` 与 `(2026-2027-1)-A0100591-01` 互为可搜。
- **教学班组成**：按分号拆分后对单个班级号全文匹配。
- **上课时间**：「星期」与「周」归一后包含匹配——`周一` 可命中「星期一第1-2节」。
- **校区**：模糊包含。

以上核心字段即使列被隐藏也参与搜索；其余字段仅当列可见时参与。搜索框置空时已选课程置顶显示。
